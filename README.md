# DevStack - Technology Stack Builder

A modern, responsive web application built with **React** and **TypeScript** that allows developers to explore, compare, and hand-pick their ideal software development stack.

🔗 **Live Demo:** [https://devstackm.netlify.app/](https://devstackm.netlify.app/)

---

## ✨ Key Features

* **Interactive Stack Management**: Dynamically add or remove technologies to/from your custom stack with live count tracking.
* **Instant Feedback**: Integrated with `react-toastify` to deliver smooth status and alert notifications whenever stack items are updated.
* **Responsive Architecture**: Fully optimized grid systems and layout designs built using **Tailwind CSS** for seamless mobile, tablet, and desktop viewing.
* **Information Modals**: Quick-access modal windows to review architecture breakdowns and development guidelines.
* **Smooth Navigation**: Jump directly to target categories and sections using built-in anchor scrolling.

---

## 🛠️ Tech Stack

* **Core Framework**: React, TypeScript
* **Styling**: Tailwind CSS, DaisyUI
* **Notifications**: React Toastify (`react-toastify`)
* **Icons & Assets**: React Icons, Iconify CDN
* **Deployment**: Netlify

## 🚀 Getting Started Locally

Follow these instructions to set up and run the project locally on your machine.

### Prerequisites

Make sure you have **Node.js** (v18 or higher) installed on your system.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/dev-stack.git

```


2. Navigate to the project directory:
```bash
cd dev-stack

```


3. Install dependencies:
```bash
npm install

```


4. Start the development server:
```bash
npm run dev

```
